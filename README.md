| ปรับปรุง | รายละเอียด |
|---|---|
| ธีม | เขียวเข้ม งาช้าง ทอง พร้อมคงสีความหมายของไพ่ |

| นำเสนอ | แสดงชื่อและอายุ ซ่อนช่องแก้ไขและหมายเหตุส่วนตัว สลับสามมุมมอง กด Esc กลับ |

## ขอบเขต

คงสูตรคำนวณ คะแนน การไฮไลต์ รูปไพ่ ระบบ Login และการบันทึก GAS จาก V9.7 ไม่ต้องเปลี่ยนรหัสผ่านหรือ Deploy GAS ใหม่ การเปิดใช้พร้อมกันสองเวอร์ชันยังอยู่ภายใต้เงื่อนไข session เดียวของ GAS เดิม

## ทดสอบ

```sh
npm ci
npx playwright install --with-deps chromium
npm test
npm run test:ui
```

- Unit tests ตรวจสูตร 1,008 ชุด ระบบรับรองการบันทึกและ Login ด้วยข้อมูลจำลอง
- Playwright ตรวจ 1366×768 และ 1920×1080 รวมโหมดนำเสนอและส่งออก PNG
- ไฟล์ `tests/backend-reference/Code.gs` ใช้จำลอง backend ในการทดสอบเท่านั้น ห้ามใส่รหัสผ่านจริงใน Repository
- ชุดทดสอบไม่บันทึกข้อมูลลง Google Sheet จริง
- GitHub Actions รันชุดทดสอบและเก็บหลักฐานภาพหน้าจอ เผยแพร่ผ่าน Pages เมื่อทดสอบผ่านเท่านั้น
